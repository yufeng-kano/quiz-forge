# 選題助手：進度與失敗重試移入對話區（H1）

## 背景

選題助手欄底（`agent__footer`）在回合進行中會顯示「處理中＋進度（如 2/5）」一行，失敗時顯示錯誤文字與重試鈕，都位在輸入框正上方。輸入區因此變成「狀態文字＋輸入框」的複合區塊，輸入欄位不再看起來只是輸入欄位。

## 決策（H1）

- 欄底（`agent__footer`）只放輸入框（composer）；輸入框永遠看起來只是輸入欄位，不承載任何狀態顯示。
- 回合進行中：進度（label＋`ProgressText`）顯示在**對話區**（訊息清單底部），一行淡色文字、不是訊息、沒有卡片框；回合結束（成功或失敗）即消失。
- 回合失敗：錯誤文字與重試鈕同樣顯示在對話區底部；重試成功後消失。
- `turnRequestError`（送出請求本身的錯誤，例如 POST 失敗）維持在欄底輸入框上方——它是送動作錯誤，不是回合狀態。
- 推翻 `docs/frontend.md` 互動原則中「欄底顯示處理中就夠」那半句：處理中改在對話區底部顯示。

## 理由

輸入欄位要一體：看起來像輸入欄位的就是輸入欄位。回合進度與失敗是對話層級狀態，屬於時間軸，放在對話區底部與訊息一起捲動，邊界清楚。
