# 選題助手回到題庫右側；題庫看得到已選、取消全選

日期：2026-08-17

## 背景

`docs/decisions/2026-08-17-bank-agent-own-pages.md` 的 D8／D9 把選題助手拆成 `/conversations` 與 `/conversations/:id`。實作後使用者明確判定：

- 不該是獨立導覽項；應該在題庫多一個可展開的右側欄。
- 對話畫面卡片套卡片（訊息框裡再套提案區、再套每題一張卡），沒有一體感。
- 題庫很難看出「到底選了什麼」；需要能切到已選清單，而不是只看一行計數。
- 「全選目前結果／全部加入選取」是不負責任的批次鈕，拿掉。
- 題卡「複製／丟棄」能改 icon 就改 icon。

D1–D6（題目向量、語意搜尋、有界迴圈、只提案不改選取、對話持久化）不在這次範圍。後端 API 不改。

## 決策

### D10 選題助手掛回題庫頁右側欄

- `/questions` 是「題庫工作區」：左欄瀏覽／已選，右欄對話。
- 右側欄可展開、可收合。收合狀態記 localStorage。窄視窗預設收合，用欄頭按鈕開關，不另開獨立頁。
- 側邊欄拿掉「選題助手」。`/conversations`、`/conversations/:id` 不再是導覽目標；舊網址 `replace` 到 `/questions`（若帶 `:id` 則打開該則對話）。
- 欄內同時有：目前對話的訊息與輸入框、切換／新增／刪除對話。不再為了「乾淨」把歷史拆到另一頁。
- 回合輪詢掛在題庫頁（欄開或關都訂閱 `pendingTurn`），離開 `/questions` 才停。同一時間仍只跑一個回合。
- 「套用到篩選」只寫入題庫篩選 store，不再換頁——人已經在題庫。
- agent 仍只提案；使用者逐題加入選取。沒有「全部加入選取」。

理由：選題是為了勾匯出，必須跟題庫勾選在同一畫面。獨立路由把提案與勾選拆開，反而看不見自己選了什麼。D8 為了乾淨付出的換頁代價，實測不被接受。

### D11 題庫左欄可切「題庫／已選」

- 工具列（或頁首附近）兩個互斥檢視：題庫（現有篩選＋分頁）與已選（`exportSelection` 的題，依勾選順序）。
- 已選是同一批 `BankQuestionCard`，可取消勾選、可複製／丟棄。不另做一張摘要卡清單。
- 已選檢視沒有「全選」；題庫檢視也沒有。選題只能逐題勾，或從助手提案逐題加入。
- 選取列只留：已選題數、切到已選、前往匯出、清除選取。計數永遠點得進已選檢視。

理由：一行「已選取 N 題」無法核對內容。全選目前結果會在篩選一變時誤收整頁，這正是使用者說的不負責任。

### D12 對話與題卡去掉套疊卡片

- 右側欄是一塊工作面（分割線分開，不是再掛一張大圓角卡）。訊息是時間軸上的文字，不是每則一張 bordered card。
- 提案是該則回覆底下的扁平列（題型、編號、單行預覽、加入），列與列之間用 hairline，不再「區卡片裡再套題卡片」。
- 題庫左欄是一塊工作面：篩選列是 flush toolbar（不要再包 `.card`），題與題之間用 hairline，不要每題一張獨立白卡漂在灰底上。複製／丟棄改成 icon 按鈕（`aria-label` 走 locale）。審題頁「採用／丟棄／編輯」是主要動作，可留文字鈕；題庫這兩個次要動作才改 icon。

## 被推翻的決策

- **D8／D9**（`2026-08-17-bank-agent-own-pages.md`）：作廢。選題助手不再是獨立兩頁，也不再佔側邊欄一項。
- **D7** 的「右側欄」方向恢復，但細節以本決策為準（與題庫／已選切換、去套疊、禁全選一起做，不是還原當日那一版面板）。

## 代價

- 題庫頁又變複雜；靠收合右側欄換回專心瀏覽。
- 舊的 `/conversations` 書籤會進題庫，對話 id 仍可用。
- 審題頁的「全選本頁再批次採用／丟棄」不在本決策範圍：那是審題隊列，不是匯出選取。

### D13 左右欄不是同一個捲動框

右側選題助手是固定高度的獨立欄：吃滿頁首以下剩餘視窗，自己不隨左欄變高。

- 左欄（篩選＋題目）只捲自己的清單。
- 右欄只捲訊息區。欄頭（標題、對話切換）與欄底（回合狀態＋輸入框）釘在欄內，捲左欄或捲訊息都不會把輸入框帶出視窗。
- 兩欄中間一條分割線。不要共用一個 overflow 父層，否則輸入框會落到「整頁最底下」。

理由：聊天輸入必須隨時在畫面上。跟題庫清單共用一個 frame，欄會被題目撐高，輸入就被推到要捲到底才看得到的位置。

### D14 提案列跳到題目，不加入選取

點助手提案列（整列可點）做這幾件事，且**不**寫入 `exportSelection`：

- 切到左欄「題庫」檢視。
- 清掉篩選（否則該題可能不在目前結果裡）。
- 左欄只顯示這一題，讓人看完整題幹／選項／答案，再用既有 checkbox 自己勾。
- 捲到該題（`scroll-margin` 避開 sticky 頁首）。

沒有「加入選取」「已在選取中」按鈕。已勾過的題列上可用淡字標「已選」，仍以跳到題目為主。

理由：預覽一行不夠判斷能不能進考卷。從右側直接加入，等於沒看過題就選。D5 的「人決定是否採用」在這裡比「少點一次」優先。

### D15 Esc 回到跳題前的搜尋畫面

跳到單題前先快照：篩選（含搜尋框文字）、頁碼、左欄捲動位置。Esc（或再按「題庫」）還原這份快照，清單與捲動回到離開時的樣子。

- Modal／選單開著時，Esc 只關浮層，不還原清單。
- 輸入框裡按 Esc 也還原清單（單題檢視時輸入不是主軸）。
- 沒有單題焦點時，Esc 不做事。

理由：為了看一題把搜尋清掉，不能害人自己重找。捲動也要還，否則回到清單還得再找剛才看到哪。
