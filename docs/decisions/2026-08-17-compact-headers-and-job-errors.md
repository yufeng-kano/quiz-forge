# 頁首精簡、狀態去 tag、任務錯誤人話化

## 決策

- `PageHeader` 不再放說明頁面用途的導覽句。標題列只留頁名，需要時同一行帶計數（「題庫 - 共 N 題」）。其他頁同樣拿掉「瀏覽／檢視／選擇…」這類廢話副標。
- 狀態一律用純文字加語意色，不用 pill／chip／tag 底色框。截圖上的「已完成」膠囊要拿掉。
- 任務中心錯誤欄不顯示程式碼級內容（`SourceReferentialPhraseError`、`type='single_choice'`、`chunks=[36]`、payload dump）。後端寫入 `jobs.error` 時就用人話摘要；完整例外只留 log。前端表格單行截斷，完整摘要用 tooltip，不做「顯示完整錯誤」展開。

## 理由

- 頁面用途已由側邊欄與標題本身說明，第二行教學句只拉長版面。
- 狀態 tag 在表格裡是裝飾，不是資訊；文字＋顏色夠用。
- 老師不是開發者，任務表不該出現 exception 字串。操作面只要知道「幾題失敗、什麼原因類別」，細節在 log。

## 影響

- 前端：各頁 `PageHeader` 副標、`StatusBadge` 樣式、任務中心錯誤欄。
- 後端：出題／補向量等 job 寫入 `jobs.error` 的字串改人話；測試改斷言摘要而不是 exception 類名。
