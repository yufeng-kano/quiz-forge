# 選題助手：輸入欄位扁平滿寬（H2）

## 背景

H1 把進度與失敗重試移出欄底後，欄底只剩輸入框，但輸入框仍是有邊框、圓角、左右留白的方塊，沒有貼齊欄寬，看起來仍像一個獨立控件，不是一體的表面。

## 決策（H2）

- 輸入欄位（composer textarea）扁平化：拿掉邊框與圓角（`border: none; border-radius: 0`），背景與欄底一致。
- 輸入欄位貼齊欄寬（左右到欄緣），欄底 `agent__footer` 的 padding 歸零；輸入欄位就是欄底整塊表面。
- 輸入欄位與對話區之間只保留欄底既有的 hairline（`border-top`）作為分隔，不另加任何邊框。
- 輸入文字的水平 padding 用 `var(--space-3)`，與對話區訊息文字對齊。
- focus 維持既有軟性 focus ring（`--focus-ring`），不畫硬邊線。
- `turnRequestError`（送出請求錯誤）仍顯示在輸入欄位上方，補上水平 padding 不貼齊欄緣。

## 理由

輸入欄位要一體：看起來像輸入欄位的就是輸入欄位，不該有獨立控件的邊框與留白。貼齊欄寬＋單條 hairline 分隔，與全站「hairline 分隔、不套卡片」的節制語彙一致。
