# 表單頁專業化：出題分欄工作區、頁首恢復頁名、匯出「題目與配分」widget

- 日期：2026-08-17
- 狀態：已決定
- 背景：使用者以出題頁與匯出頁截圖回報「頁面很醜、沒有專業感」。同日稍早的設計節制決策（D16–D24）把頁名、區塊標題、卡片全部拿掉之後，稀疏的表單頁（出題、匯出）失去版面錨點：表單浮在左上角、右欄只剩一行淡字、原生控制項寬度失衡（題型 select 拉滿欄寬、題數輸入框極窄）。另外匯出頁已選題目清單攤平在表單上方，一多就要捲動；逐題配分存在頁面元件 local state，離頁即消失（bug）。

## D25：頁首恢復顯示頁名（推翻 D23）

- `PageHeader` 恢復顯示可見頁名（`pageName`），不再只留視覺隱藏的 `<h1>`。
- 理由：表單類頁面沒有滿版表格或統計卡當視覺錨點，去掉頁名後整頁像未完成品。頁名是版面錨點，不只是側邊欄的重述；業界後台（Stripe、Linear 等）皆保留頁名。
- 文件詳情維持 `heading`（資料標題）取代頁名的行為。
- D23 其餘部分不變：頁首仍不放用途說明句、教學句。

## D26：出題頁改左右分欄工作區

- 出題頁套 `page--workspace`：左欄表單（自體捲動、限制行寬），右欄固定寬度「出題紀錄」rail，之間一條分割線，rail 有自己的欄頭（標題＋筆數）與捲軸。
- 空狀態置中在 rail 內，不再是浮在頁面右上角的一行字。
- 窄幅（≤960px）退回單欄自然高度，紀錄區以上分隔線接在表單後。

## D27：表單分區塊加小節標題（收斂 D19 在表單頁的適用）

- 多欄位表單以區塊分組並加小節標題（出題頁：「出題範圍」「題目設定」；匯出頁：「考卷設定」「題目與配分」「表頭欄位」），區塊間以 hairline 分隔。
- 理由：表單分組標題是導引結構，不是重述；表單設計通則（欄位分組、單欄排列、欄寬符合預期內容）都要求分組可見。
- D19 仍適用於「內容自明的單一區塊」（例如只有一張表格的頁面不需要再加「清單」標題）。

## D28：全站表單控制項升級

- `main.css` 統一控制項樣式：一致高度、自訂 select 下拉箭頭（inline SVG，去原生外觀）、focus ring（`--focus-ring` token）、hover 邊框色、數字欄位 `tabular-nums`。
- 控制項寬度必須符合預期內容：題數／配分等數字欄固定窄寬，題型／難度 select 有上限寬度，不再拉滿整欄。
- 表單內獨立成行的「新增列」動作改為 icon＋文字（例如「＋ 新增題型」）；列內的移除維持 icon-only。孤立的「＋」方塊辨識度不足，是 D18 icon 優先原則的例外。

## D29：匯出頁「題目與配分」合併 widget（推翻攤平清單）

- 已選題目清單不再攤平在匯出頁面上（原本 20rem 有界捲動框）。改成與出題頁 scope picker 同形的「觸發按鈕＋Modal」widget：頁面上只留一行摘要（已選題數、合計配分），Modal 內是逐題列表（題號、題型、預覽、逐題配分輸入、移除）＋每題型預設配分＋依目標總分平均分配。
- `ExportSelectionList`、`ExportScoringField`、`ExportScoringModal` 三個元件合併為 `ExportQuestionsField` ＋ `ExportQuestionsModal`。
- 「已不在已採用題庫」的警示仍在頁面上顯示（它會讓匯出失敗，不能藏進 Modal）。

## D30：逐題配分移入 `exportSelection` store（bug 修正）

- 逐題配分原本是 `ExportsView` 的 local ref，離開匯出頁（例如回題庫補選題）再回來就整組消失。
- 改存進 `exportSelection` Pinia store（session 內，不落 localStorage），取消選取某題時同步刪掉該題配分；`clear()` 一併清空。
- 每題型預設配分維持在 `exportPrefs`（localStorage）不變。
